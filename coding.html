PixiJS Location Check

Made for a creative coding project during college, this piece of code is used to check the location of two "eye" shapes. If the check is true, the eye will be dragged into it's exact place but if it is still false the eye will return to where it was. When checked to true, the code will also trigger a check sound effect. For this exercise I personally chose to create a minigame in which you would create Kirby in reference to the old "How to draw Kirby" videos.
